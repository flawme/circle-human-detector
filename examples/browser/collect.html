Circle capture collector

Consent-gated pointer capture for circle-human-detector. Nothing is recorded before you consent; nothing is ever transmitted.

Before recording can start

  • What is captured: while you draw on the canvas, this page records pointer x/y positions, millisecond timestamps, pressure, pointer type (mouse/touch/pen) and contact width.
  • Where it goes: nowhere. This page makes no network requests. Samples stay in this tab's memory until you export them to a local JSON file.
  • Why: the exported file is a labeled real capture for evaluating the detector. It is behavioral, biometric-adjacent movement data — share it only with datasets you trust.
  • Withdraw any time: the Withdraw button stops recording and deletes every recorded sample immediately.
